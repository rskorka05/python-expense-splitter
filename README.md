# Python Expense Splitter

A console application written in Python for splitting shared expenses and calculating balances between participants.

The project was created as part of my university programming coursework and is intended to demonstrate my practical knowledge of Python fundamentals.

## Features

* Adding participants and their expenses
* Storing expense data in a JSON file
* Calculating total expenses
* Calculating the cost per participant
* Comparing individual payments with the calculated share
* Displaying balances for participants
* Input data validation
* Error handling

## Technologies

* Python
* JSON

## Python concepts used

The project uses several Python concepts, including:

* functions
* lists and dictionaries
* loops and conditional statements
* mathematical calculations
* file operations
* JSON serialization and deserialization
* exception handling with `try/except`
* data validation

## How to run

1. Make sure Python 3 is installed.
2. Download or clone this repository.
3. Run the application:

```bash
python main.py
```

The application uses `podzial_kosztow.json` to store expense data.

## About the project

This project was developed during my first year of engineering studies as part of the *Programming Fundamentals* course.

Its purpose was to practice structuring a Python application, working with persistent data and implementing calculations related to shared expenses.
